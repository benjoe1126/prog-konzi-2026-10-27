# Prog1 konzi 2026.10.27
Ez a repo C kódrészleteket tartalmaz, elsősorban függvények, illetve programozási tételek témakörben.

## Hibák, hibák javítása
Ha bármely kódban hibát találsz úgy nyiss egy pr-t, amint időm engedi ránézek.
Fontos, hogy ez NEM egy C programozás best practice útmutató, kérlek a "void* itt nem safe" és egyéb hasonló hibákat tessék ignorálni, mivel ezek csak demonstráció kedvéért szerepelnek a legtöbb helyen.

## Functions

A `functions` mappában található kódok a függvényeket mutatják be, az egyszerű esetektől kezdve az összetettebb esetekig (pl. higher order functions).  
Ezen felül demonstrál pár, típus és memória kezelési sajátosságot is (void, mint return type, stack vs heap allocated memory return)
